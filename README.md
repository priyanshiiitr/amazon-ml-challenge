# Amazon ML Challenge 2026 — Business Entity Resolution

Match every Source 1 business entity to the Source 2 / Source 3 records that
describe the same real-world business. Scored by macro-averaged F_0.5 (per
entity, singletons included).

**Current state:** validation macro F_0.5 **0.92102**, leaderboard **0.883**
(from an earlier model; the 0.921 model's submission is ready to upload).
Blocking recall 0.9251 at **68 candidates per entity**.

## Pipeline

| Module | Role |
| --- | --- |
| `translit.py` | Indic → Latin transliteration across nine scripts, dependency-free |
| `normalize.py` | Accent/legal-suffix/abbreviation cleanup, **consonant skeleton**, leading-zero stripping |
| `prep.py` | Streams raw TSVs into normalised parquet at bounded memory |
| `retrieve.py` | Hashed-key inverted index, IDF cosine, sharded top-K |
| `run_blocking.py` | Forward candidate generation (S1 → S2/S3), parallel over shards |
| `reverse.py` | **Reverse retrieval** (S2/S3 → S1) — source of the strongest feature |
| `merge_cands.py` | Unions forward + reverse, keeping retrieval provenance |
| `competition.py` | Per-candidate competition features (who else claims this record) |
| `tokidf.py` | Token document frequencies, for name-rarity features |
| `pairfeat.py` | ~60 pair features incl. rank-relative and cluster-support |
| `run_model.py` | LightGBM training, prediction, submission writing |
| `expected_f.py` | Expected-F_0.5 set-size selection |
| `decision.py` | Threshold grid search against the real metric |
| `evaluate.py` | The competition metric + singleton/non-singleton breakdown |
| `stack.py`, `predict_stack.py` | Two-stage stacking (**written, not yet validated**) |

## Reproduce

```bash
pip install -r code/business_entity_resolution/requirements.txt
cd code/business_entity_resolution

python -m src.prep train && python -m src.prep test
python -m src.tokidf train && python -m src.tokidf test

# forward + reverse candidates, then union
python -m src.run_blocking train --sample 300000 --top-k 120 --workers 8 \
    --out work/cands_train_300k.parquet
python -m src.reverse train --top-k 3 --out work/rev_train_full.parquet
python -m src.merge_cands --fwd work/cands_train_300k.parquet \
    --rev work/rev_train_full.parquet --fwd-k 60 --rev-k 3 \
    --out work/union_train.parquet
python -m src.competition work/union_train.parquet work/union_train_comp.parquet train

python -m src.run_model train --cands work/union_train_comp.parquet

# same on test, then predict
python -m src.run_blocking test --top-k 120 --workers 8 --out work/cands_test_k120.parquet
python -m src.reverse test --top-k 3 --out work/rev_test.parquet
python -m src.merge_cands --fwd work/cands_test_k120.parquet \
    --rev work/rev_test.parquet --fwd-k 60 --rev-k 3 --out work/union_test.parquet
python -m src.competition work/union_test.parquet work/union_test_comp.parquet test
python -m src.run_model predict --cands work/union_test_comp.parquet
```

Then validate:

```bash
cd student_resource
python3 utils/validate_submission.py --matching ../output/matching_results.tsv \
    --candidate ../output/candidate_pairs.tsv --test-dir dataset/test
```

Seeds are fixed (`SEED=42`). A full cycle is ~3 hours on 16 cores / 62 GB.

## The three findings that produced the score

1. **Cross-script matching.** Source 1 is 100% Latin; ~23% of Indian Source 2/3
   names are in nine Indic scripts. The original normaliser mapped them to the
   empty string. Transliteration plus a voicing-folded consonant skeleton took
   mean similarity on those pairs from **4.3 to 86.0**.
2. **Address-only blocking keys.** 68.6% of otherwise-unreachable true links had
   the business name replaced by an unrelated token while the address survived.
   Every name-anchored key is blind to them.
3. **Reverse retrieval as a feature.** Querying from Source 2/3 into a Source 1
   index does *not* improve recall (0.856 alone vs 0.917 forward), but the
   resulting `rev_rank` — "is this entity this record's single best owner among
   all 2.2M?" — became the **top feature by 5×**. Exclusivity holds exactly in
   the ground truth, which makes it near-decisive.
